# Shareable demo: plan and status

Last updated: 2026-11-17. The **debug overlay works in the Editor** (first
version, see [debug-ui.md](debug-ui.md)). The web build and the demo shell are
not started.

## Objective

A playable demo that tutors and designers can open from a link, to see where
the engineering stands, without installing Unity or owning the controller.

Two things are needed for that:

1. **An automated web build**, so every push produces a fresh, linkable build.
2. **A heavy debug UI**, so a sighted visitor can try everything: jump to any
   point of the story, trigger every interaction, see what the audio engine and
   the controller are doing, and change the tunables live.

The demo is a showcase for sighted adults. The game itself stays audio-only
(see [../vision.md](../vision.md)), so the debug UI must be an overlay that can
be hidden to show the real experience.

## Open decisions

These are the user's to make. Each has a recommendation.

| # | Decision | Recommendation | Blocks |
|---|---|---|---|
| 1 | **Where the build is hosted.** The repository is private; a GitHub Pages site is public even when the repository is private, and needs a paid plan (Pro, or the student pack) for a private repository. | GitHub Pages if the plan allows it, otherwise itch.io with a restricted page. See [web-build.md](web-build.md#hosting). | W-12, W-13 |
| 2 | **Whether voices and sounds may be public.** A public URL exposes the ElevenLabs voices and the Sonniss-derived sounds inside the build. Sonniss allows use in a game but not redistribution of the raw files. | Treat the URL as unlisted and share it by hand, or use itch.io's restricted access. | W-13 |
| 3 | **Where the build runs.** Cloud CI needs the Unity Personal licence file and account password stored as repository secrets. A local build needs the Web module installed on the Mac (about 2 GB). | Cloud CI with GameCI, plus the local module for the spike. | W-01, W-11 |
| 4 | **How the hall reverb and distance muffling are handled on the Web**, where Unity's reverb zones and low-pass filters are expected not to work. | Decide after the spike (W-02) confirms it. First choice is accepting a drier web build and saying so in the demo. | W-07 |

## Rules for agents working on this

- Read [current-state.md](current-state.md) first. It lists facts that were
  measured on 2026-11-16; re-check any that your task depends on.
- When a task is finished, tick it in its document and update the "Last
  updated" date. When a phase is finished, update
  [../roadmap.md](../roadmap.md).
- Scenes are generated by builders in `Assets/EchoQuest/Editor/`. Change the
  builder, not the `.unity` file.
- Installing the Web module, adding repository secrets, enabling Pages and
  pushing are human actions. Ask first.
- The existing checks must keep passing. They are listed in
  [../scena1-interattiva.md](../scena1-interattiva.md).
